# FX 外汇交易模拟器 — 游戏策划案（GDD v0.1）

> 定位：单人网页端「外汇交易模拟经营」游戏，1 人独立开发，纯前端、无后端、可离线运行。
> 目标：让玩家在零风险环境中体验「分析 → 下单 → 持仓 → 结算」的决策快感与净值曲线的成长反馈。

---

## 一、项目概述

### 1.1 一句话定位
用虚拟资金在程序化生成的行情中做外汇/贵金属/加密货币保证金交易，通过风控与策略把账户做大，解锁更高资金规模、更多品种与更强工具。

### 1.2 核心体验循环（Core Loop）

| 层级 | 循环内容 | 时长 |
|---|---|---|
| 微循环 | 看盘 → 判断方向 → 设仓位/止损止盈 → 开仓 → 持仓 → 平仓结算 | 15 秒 ~ 3 分钟 |
| 中循环 | 一轮交易日/周：完成挑战目标（如「日内 2% 收益」） | 5 ~ 15 分钟 |
| 长循环 | 账户等级成长：资金里程碑 → 解锁品种/杠杆/指标 → 挑战更高资金盘 | 数小时 |

### 1.3 目标用户与卖点
- 对交易/金融/数字增长感兴趣的轻度玩家；不需要真实金融知识也能上手。
- 卖点：**短局爽感 + 可复盘的确定性行情 + 数字成长（净值曲线）**。

### 1.4 平台与约束
- Web（PC 浏览器为主，移动端浏览器兼容）；`localStorage` 存档；无登录无服务器。
- 单局数据全部本地计算，行情由种子（seed）生成，可复现、可回放、可分享种子挑战。

## 二、核心玩法设计

### 2.1 基础操作
1. 选择交易品种（EURUSD / GBPUSD / USDJPY / XAUUSD / BTCUSD …）
2. 选择时间周期（M1 / M5 / M15 / H1 / H4 / D1）
3. 分析行情（K 线 + 技术指标 + 新闻事件提示）
4. 下单：方向（做多/做空）、手数（0.01 起）、杠杆、止损（SL）、止盈（TP）
5. 持仓中：净值实时波动，可移动止损、加仓、部分平仓
6. 平仓：手动 / 触发 SL、TP / 触发强平

### 2.2 时间推进
- Tick 驱动（默认 1 tick = 1 秒 = 1 根 M1 K 线的 1/N）。
- 时间倍速：`暂停 / 1x / 2x / 5x / 20x`，倍速越高越考验预设止损。
- 「当日结算」与「隔夜利息（Swap）」在跨日时结算。

### 2.3 交易品种表（配置示例）

| 代码 | 名称 | 点差(pip) | 合约大小 | 波动率档 | 解锁条件 |
|---|---|---|---|---|---|
| EURUSD | 欧元/美元 | 1.2 | 100k | 低 | 初始 |
| GBPUSD | 英镑/美元 | 1.8 | 100k | 中 | 初始 |
| USDJPY | 美元/日元 | 1.4 | 100k | 中 | 等级 3 |
| XAUUSD | 黄金 | 25 | 100oz | 中高 | 等级 5 |
| BTCUSD | 比特币 | 1200 | 1 | 极高 | 等级 8 |

> 参数均为可调配置，集中在 `config/instruments.js`，不做硬编码。

### 2.4 订单类型（MVP → 进阶）
- MVP：市价单（Buy/Sell）、止损 SL、止盈 TP。
- 进阶：限价挂单（Buy Limit / Sell Limit / Buy Stop / Sell Stop）、追踪止损、部分平仓、OCO。

### 2.5 杠杆与风控
- 可选杠杆：1 / 10 / 20 / 50 / 100 / 200 / 500（随等级解锁）。
- 保证金 = 合约价值 / 杠杆；保证金率 < 100% 触发追加保证金，< 50% 强制平仓（爆仓）。
- 明确 UI 预警：保证金率黄/橙/红三档提示。

## 三、数值系统设计（最关键部分）

### 3.1 行情生成引擎
采用 **几何布朗运动（GBM）+ 波动率状态机 + 事件跳跃**，兼顾真实感与可调难度。

\[
S_{t+1} = S_t \cdot \exp\left[\left(\mu - \frac{\sigma^2}{2}\right)\Delta t + \sigma\sqrt{\Delta t}\cdot Z\right], \quad Z \sim N(0,1)
\]

- `μ`：漂移项，默认趋近 0（避免长期单边），可由「趋势剧本」覆盖。
- `σ`：由**波动率状态机**动态给出：

| 状态 | σ 系数 | 平均持续 | 触发方式 |
|---|---|---|---|
| 平静（亚洲盘） | 0.6x | 60 tick | 默认回落 |
| 常规（欧美盘） | 1.0x | 120 tick | 默认 |
| 高波动 | 2.0x | 40 tick | 随机 / 事件前 30 tick |
| 事件冲击 | 4.0x + 跳跃 ±2% | 15 tick | 新闻事件 |

- **事件跳跃**：在财经事件时刻注入一次性跳空（模拟非农、CPI、央行决议），带滑点风险。
- **确定性**：使用可播种伪随机（`mulberry32`/`seedrandom`），同一 seed 行情完全一致 → 可做「种子挑战榜」。

### 3.2 K 线聚合
- 引擎只产出 tick 价格，按时间周期聚合为 OHLC K 线，缓存增量更新（避免每帧重算）。
- 历史 K 线预生成 500 根，之后实时推进。

### 3.3 账户数值

| 字段 | 说明 |
|---|---|
| Balance 余额 | 已实现资金（不含浮盈） |
| Equity 净值 | Balance + 浮动盈亏 |
| Margin 已用保证金 | Σ(合约价值 / 杠杆) |
| Free Margin 可用保证金 | Equity − Margin |
| Margin Level 保证金率 | Equity / Margin × 100% |
| PnL | (现价 − 开仓价) × 方向 × 手数 × 合约大小 × 点值 |

- 强平规则：Margin Level < 50% 时，按亏损最大订单依次强制平仓。
- 成本：点差（开仓即浮亏）+ 手续费（可选）+ 隔夜利息（持仓跨日，多空双向）。

### 3.4 难度与成长曲线
- 起始资金：$1,000（可选「新手 $500 / 标准 $1,000 / 高手 $10,000」）。
- 等级经验来自：盈利平仓、连续盈利、完成挑战、最大回撤控制优秀。
- 解锁树：等级 → 新品种 / 更高杠杆 / 更多指标 / 更大资金盘 / 多仓位并发数。
- 反向约束：爆仓 → 降回上一资金档（软惩罚，不清档存档），保留「破产重开」。

### 3.5 挑战系统（提供目标感）
- 每日挑战：如「今日 +2% 且不触发强平」「只用 3 单完成 +1%」。
- 种子挑战：固定 seed 排行榜（本地记录最佳成绩）。
- 成就：首次盈利、首次爆仓、10 连胜、单笔 10R 收益等。

## 五、界面与交互

### 5.1 布局
```
┌──────────────────────────────────────────────┐
│ 账户栏：Balance | Equity | Margin | Level 倍速控制 │
├───────────────────────────────┬──────────────┤
│                               │  下单面板     │
│        主图表区（K线+指标）     │  持仓列表     │
│                               │  挂单列表     │
│                               │  成交历史     │
├───────────────────────────────┴──────────────┤
│ 底部：品种切换 | 周期切换 | 事件提示条         │
└──────────────────────────────────────────────┘
```

### 5.2 关键交互
- 图表上直接拖拽持仓的水平线调整 SL/TP（强反馈）。
- 右键持仓 → 一键平仓 / 部分平仓 / 反手。
- 快捷键：`B` 买入、`S` 卖出、`空格` 暂停、`1~5` 切换周期。
- 移动端：底部 Tab 切换「图表 / 下单 / 持仓」，图表支持双指缩放。

### 5.3 反馈设计（低成本高爽感）
- 平仓盈利：绿色数字跳动 + 音效 + 净值曲线上扬。
- 接近强平：屏幕边缘红色脉冲 + 警报音。
- 爆仓：全屏灰化 + 「账户清算」结算页 + 复盘按钮。

- **风格**：深色金融终端风（背景 `#0d1117`，涨绿跌红/国际配色可切换）。

## 七、技术方案（Web）

```
fx-sim/
├─ index.html
├─ src/
│  ├─ engine/     # 行情引擎、订单撮合、账户结算（纯逻辑，无 DOM）
│  ├─ chart/      # Canvas K线渲染
│  ├─ ui/         # 面板、表单、交互
│  ├─ data/       # 品种/事件/解锁/成就 配置表
│  └─ save/       # localStorage 存档与种子
└─ config/
```

- **栈建议**：Vite + 原生 JS（或 TS）；不引入重型框架，减少心智负担。
- **图表**：优先用 `lightweight-charts`（~45KB，金融图表专业、性能极好）；若要完全自控再手写 Canvas。
- **状态**：单一 `GameState` + 简单事件总线（`emit/on`），引擎 tick 与渲染 rAF 解耦。
- **确定性与可测**：引擎纯函数化 + seed，可写单测（如「同一 seed 行情一致」「强平阈值正确」）。
- **性能**：K 线增量绘制；tick 逻辑与渲染分离（逻辑固定步长，渲染插值）。

## 十、风险与合规

- **免责声明**：启动页与设置页明确「虚拟货币、非真实交易、不构成任何投资建议」。
- **伦理边界**：不接入真实行情做诱导、不引导实盘开户、不做充值变现（纯单机）。
- **数值风险**：波动率过高导致「无脑梭哈也能赢」→ 通过 Swap、点差、回撤惩罚平衡。
- **挫败风险**：爆仓惩罚过重导致流失 → 采用软惩罚（降档而非清零）+ 复盘回放。
